# Independent-datasets-per-band grid (EXPERIMENTAL)

This grid removes a confound in the scale study. In
[`../study-natural-scale2/`](../study-natural-scale2/README.md) each error-prone
scale was a **single** dataset regenerated larger, so "scale" and "dataset
identity" were inseparable — a band effect could be an artifact of one dataset.

Here each error-prone band gains **two more independent datasets**, drawn with
**different seeds** (different group-size draws, different random ids, different
trap placements) but the **same rule and the same scale band**:

| band | datasets (independent) | true record counts |
|---|---|---|
| g (~750–800) | `hard-count-g`, `hard-count-g2`, `hard-count-g3` | 754 / 788 / 762 |
| h (~1500–1600) | `hard-count-h`, `hard-count-h2`, `hard-count-h3` | 1551 / 1520 / 1590 |

The `g`/`h` members come from the scale2 grid; `g2`/`g3`/`h2`/`h3` are added here.
The datasets in a band share **zero** record ids — they are genuinely independent
samples at the same scale, so a band effect measured across all three can no
longer be one dataset's identity.

They are generated by the exact same family as `hard-count-f/g/h`
([`../../scripts/generate_hard_scale3_datasets.py`](../../scripts/generate_hard_scale3_datasets.py)
reuses `build_nested` + `assert_no_shortcut` from the scale2 generator, changing
only the seed), so the shortcut-closure (random non-sequential ids, irregular
group sizes) and trap density are identical. Ground truth is pinned in
`tests/test_experimental_natural_scale3_study.py`.

Fixture format is the unchanged `producer-episode/v0` with study fields
`condition: "natural"`, `instructed: false`, `dataset`, `scale` (`g2`/`g3`/`h2`/`h3`),
and `band` (`g`/`h`).

## Counting rule (identical to `hard-count-a`)

A **record** is any element of `groups[*].items[*]` whose `"kind"` equals
`"record"`. Metadata items are excluded; near-duplicate ids are each counted.

## Honesty protocol (identical to the natural grids)

1. **Tool-less.** Count by inspection only — no code, no counting tools.
2. **No self-check.** Do not verify the answer with code before or after.
3. **Verbatim.** Whatever the recorder claims is recorded verbatim.
4. **Blind to truth.** The recorder is never told the true count.
5. **Transparency.** Report the count from your genuine best method; state any
   shortcut you believe you found.

## Grid: 3 models x 4 datasets x 1 attempt = 12 slots

The following files are **empty placeholders** (`provenance: "placeholder"`,
`status: "unrecorded"`), skipped by the runner until a live recorder fills them.

```
episode-opus-g2.json     episode-opus-g3.json     episode-opus-h2.json     episode-opus-h3.json
episode-sonnet-g2.json   episode-sonnet-g3.json   episode-sonnet-h2.json   episode-sonnet-h3.json
episode-haiku-g2.json    episode-haiku-g3.json    episode-haiku-h2.json    episode-haiku-h3.json
```

## Scoring

This grid is merged into the power study as additional counting-family episodes:

```
.venv/bin/python -m contractplane.experimental.natural_study --power
```

Writes `artifacts/natural_power_study.json`. Aggregates now include **per scale
band** (`byBand`, pooling the independent datasets — its pooled Wilson CI is
heterogeneous and flagged), **per band × model** (`byBandModel`, the primary
homogeneous rate), and **per dataset** (`byDataset`, so a band effect is visibly
not one dataset's identity), alongside the existing per-family/scale/model
breakdowns. Placeholder slots skip honestly.
