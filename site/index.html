v0.1 is an alpha design and reference kernel.

The project currently validates a DomainPack candidate, compiles deterministic ExecutionPlan waves, and provides an experimental local transition kernel. It does not invoke agents or tools, evaluate selectors or conditions, enforce authority, issue independent Verdicts, process steering invalidation, or implement capability canary, promotion, and rollback. Not the other ACPs.

ContractPlane is the Agent Contract Plane. It is not Agent Client Protocol, which connects editors and coding agents, and it is not the IBM/BeeAI-origin Agent Communication Protocol, now part of A2A under the Linux Foundation. Those protocols may be used by future adapters.

ContractPlane is an early-stage proposal and reference kernel. See the repository STATUS.md before relying on a feature. contractplane.dev
